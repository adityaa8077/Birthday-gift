## 🎯 Customization

### Change Text Content

Edit files in `src/components/`:
- `HeroSection.tsx` - Opening lines and title
- `TheGirlWhoDared.tsx` - First section story
- `SayingYes.tsx` - Leadership journey
- `MomentsNobodySaw.tsx` - Hidden struggles
- `GraceUnderPressure.tsx` - Grace section
- `BuildingPlatform.tsx` - Platform building
- `Milestones.tsx` - Achievement cards
- `TheIIMMoment.tsx` - IIM reveal
- `FinalSection.tsx` - Closing message

### Swap Images

Replace files in `public/images/`:
- Keep the same names (image1.jpeg, image2.jpeg, etc.)
- Or update file paths in components

### Adjust Colors

Edit `tailwind.config.ts`:
```typescript
colors: {
  deepBlack: '#0A0A0A',  // Change these!
  warmGold: '#D4AF37',
  softIvory: '#F5F2E8',
  amberHighlight: '#FFB347',
}
```

## 🆘 Troubleshooting

### "npm: command not found"
→ Install Node.js from [nodejs.org](https://nodejs.org/)

### Port 3000 already in use
→ The site will automatically use port 3001 or 3002

### Images not loading
→ Clear browser cache (Ctrl + Shift + R)
→ Check images are in `public/images/`

### Layout looks broken
→ Wait for npm install to complete
→ Refresh the page
